# Spotify & YouTube EDA

Exploratory data analysis of a combined Spotify/YouTube performance dataset.

## What I did
- Cleaned the dataset: handled missing values, removed duplicates and unnecessary columns
- Analyzed top artists and tracks by total views + streams
- Compared YouTube views vs. Spotify streams separately to see platform differences
- Analyzed album type distribution and track "likes" performance

## Tools
Python (pandas, matplotlib)

## Data source
Spotify and YouTube dataset (Kaggle)
