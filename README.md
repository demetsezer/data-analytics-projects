# HRSA State Health Metrics Dashboard

Tableau dashboard analyzing federally funded health center (HRSA) data across U.S. states from 2017–2021.

## What it covers
- Hypertension, diabetes, and asthma rates and control rates by state
- Total patient counts and cost per patient across health centers
- Year-over-year trends (2017–2021)
- Correlation between total patient population and disease control rates

## Tools
Tableau (calculated fields, time series, correlation analysis)
